# Distribution boundary

| Classification | Contents |
|---|---|
| SAFE TO COMMIT | Original tools, synthetic tests, schema, reviewed documentation |
| GENERATED LOCALLY | SQLite database, manifests, metadata bundles, caches, captures, exports |
| USER-SUPPLIED | Original legally obtained accessible PS4 game data and references |
| NEVER DISTRIBUTE | Commercial executables/assets/audio/video/DLC, SDKs, firmware, keys, credentials, protected console materials |

Generated locally does not mean safe to publish. Review each report before public
sharing; relative paths and metadata may still be sensitive. Ignore rules are a
guardrail, not an exhaustive content audit. Keep game directories outside the repo.
No access-control bypass or decryption is implemented. Translation distribution
and patch licensing require a separate decision before release.
