Read docs/CANONICAL_PROJECT_INSTRUCTIONS.md, PROJECT_STATE.md, NEXT_ACTIONS.md,
and DO_NOT_REPEAT.md before work. The canonical target is the user-supplied PS4
Sengoku BASARA 4 Sumeragi Anniversary Edition; internal build identity is unverified.

Preserve source game data. Never publish game bytes, extracted strings, private
reports, SDKs, keys, credentials, or derived commercial assets. Public CI uses
synthetic fixtures. Do not infer edition/content solely from external filenames.

memory. No dummy runtime counts toward a game milestone.
