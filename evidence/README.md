# Validation evidence

Public evidence contains only our tooling tests and sanitized findings. Keep game
reports/captures, binary fragments, and hashes with identifying paths under ignored
`reports/`, `local/`, or `cache/` until reviewed. Preserve failed attempts as well
as passes. Link claims to exact commands, source revisions/hashes, and test scope.

Synthetic tests validate tooling, never game functionality. Remote CI configuration
is not evidence of a CI run. No behavioral comparison to PS4 has run.
